# 鼠标拼音输入（MSI · Mouse-based Syllable Input）

用鼠标完成中文输入：**滚轮选取、左键确定、右键/侧键切选字、侧键撤销**。
拼音与候选由系统输入法（微软拼音）承接，本程序把鼠标操作翻译成键盘按键。

## 获取与运行

**方式 A · 便携包（推荐普通用户）**：下载 `MousePinyin.zip`（见 Releases），
解压到非系统目录，双击 `MousePinyin.exe` 即用（全局钩子模式用
`启动-全局钩子.bat`）。无 Python 依赖、无安装过程。

**方式 B · 从源码运行**：需要 Python 3.13+。

```bat
git clone <本仓库地址>
cd <仓库目录>
install.bat
```

`install.bat` 一键完成：创建 venv → 阿里云镜像装依赖（PySide6/pynput/comtypes）
→ 生成 `start-demo.bat`（普通）/ `start-demo-global.bat`（全局钩子，Ctrl+Alt+M）/
`start-demo-debug.bat`（带控制台调试）三个启动脚本。

数据许可与来源声明见 [NOTICE.md](NOTICE.md)。

## 一、使用前准备

1. 输入法切换到**微软拼音（中文模式）**；
2. 点开任意输入框（记事本 / 聊天窗 / 浏览器地址栏）——本程序不抢焦点，
   模拟按键会发往当前焦点窗口；
3. 双击 `启动Demo.bat` 启动（重复启动会被单实例锁拦下并提示）。

## 二、操作逻辑（一张表）

| 鼠标操作 | 作用 |
|---|---|
| **滚轮** | 移动选中项（滚到头自动回绕） |
| **左键** | 确认当前选中项（点窗口内任意位置都确认选中项，不用瞄准）；音节拼完后首项 **␣ 上屏** = 直接发空格上屏整句候选 |
| **右键** | 逐字退格（拼错了一个个字母往回退，删空自动回声母层） |
| **侧键 X2** | 撤销整个音节（自动多次退格回声母层） |
| 侧键 X1 / 中键 | 无功能 |
| 候选精确选择 | 由微软拼音候选窗承载（数字键 / 翻页），Dock 不重复展示 |

整句流示例「你好」＝ `n → i → h → ao`（每步滚轮+左键，微软拼音自动分节
ni|hao）→ 拼完滚到 **␣ 上屏** 左键 → 整句上屏；想继续打字则直接滚到下一
声母继续拼。**任何时候右键/X2 都能往回退，不存在卡住的菜单。**

窗口操作：**⠿**（外框顶边）按住拖动位置｜**⚙** 设置｜**✕** 退出；
全局热键 **Ctrl+Alt+Q** 退出。

### 全局模式（P4，可选）

- 命令行 `demo_main.py --global` 启用全局鼠标钩子模式：鼠标事件由系统级
  钩子采集（滚轮/左键/右键/侧键语义与上表完全一致），⚙/✕/⠿ 按钮点击不受影响。
- **Ctrl+Alt+M** = 输入会话总开关：按一次 Dock 隐藏、鼠标全部恢复正常
  （打游戏/看视频时防误触），再按恢复。
- 不带参数启动 = 普通模式（Qt 窗口事件，行为与之前版本一致）。

## 三、输入一个字 / 一句话

**单字「你」＝ 2 步**：

```
滚轮选 n ──左键──▶ 滚轮选 i ──左键──▶ （音节 ni 完成，微软拼音出候选）
──滚到 ␣上屏 ──左键──▶ 空格上屏「你」（或继续滚选下一声母整句流）
```

**整句「你好」＝ 连续拼 + 一次上屏**：`n → i → h → ao`（每步滚轮+左键，
微软拼音自动分节 ni|hao，整句候选实时变化）→ 滚到 **␣ 上屏** → 左键上屏。

**出错了**：
- 拼错音节 → **X2** 撤销整个音节重拼；
- 只错一两个字母 → **右键**逐字退格；
- 上屏后才后悔 → 在输入框里按退格（或用微软拼音的重新转换）。

**选非第一个候选**：微软拼音候选窗里直接按数字键（Dock 不重复展示候选——
候选窗本就贴在输入框旁边，D-055）。

## 四、两层韵母（为什么韵母分两步）

韵母先选**韵头组**（a/o/e/i/u/ü，≤6 项），再选组内**韵尾**（≤10 项按
频率排序）。好处：单屏选项永远少、且组内只有 1 项时一步直发不啰嗦。
带 ü 的音节在 i/u 组里（程序内部以 v 编码，显示自动转 ü）。

## 五、设置（⚙）

| 项目 | 说明 |
|---|---|
| 皮肤 | 10 款，含 3 款**透明玻璃**（空气/冰晶/薄暮玫瑰） |
| 玻璃质感 | 素面 / 玻璃 / 磨砂 / 棱镜（色散、折射、流光、厚度组合） |
| 玻璃背景采样 | 开 = 透明玻璃折射真实桌面背景（液态玻璃）；关 = 平涂透明 |
| 字体大小 | 14~28 px（只影响文字） |
| 整体大小 | 0.7×~1.5×（键帽与窗口整体缩放） |
| 液态玻璃强度 | 0~1 |
| 滚轮灵敏度 | 2~5 格/项，默认第一档 2（越大越稳） |

全部实时生效并自动保存；「恢复默认」一键回出厂。

## 六、已知边界（诚实声明）

- 演示阶段鼠标操作需在 Dock 窗口内；`--global` 全局钩子模式已实现
  Ctrl+Alt+M 总开关与全局采集（真实三场景手测验收中）
  属下一阶段（P4）；
- 提权窗口（管理员运行的程序）可能收不到模拟按键（Windows 隔离限制）；
- 选字确认后的自动返回依赖读取目标文本，少数非标准控件读不到时会
  停在选字模式并标注「组合未知」（可用 X1 手动返回，不会误清空）；
- 透明玻璃的背景采样含瞬时排除自身处理：极小概率下您手动截图恰好撞上
  采样瞬间，截图中会缺少键帽条（重截即可）；如介意可在设置中关闭。

## 七、排障

| 现象 | 处理 |
|---|---|
| 滚轮没反应 | 确认光标在键帽条窗口内；设置里把灵敏度调回 2 |
| 打不出中文 | 检查输入法是否微软拼音·中文模式；焦点是否在输入框 |
| 双击没反应 | 已有实例在运行（看屏幕底部键帽条）；重复启动被锁拦 |
| 想退出 | ✕ 按钮或 Ctrl+Alt+Q |
| 调试排错 | 用 `启动调试.bat`（带状态面板：模式/高亮/发键记录对照） |
